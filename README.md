# SapeaAlToque

*Sapea y pide.*

## ¿Qué es?

Un catálogo virtual para pequeños emprendedores. Presente, organice y ofrezca sus productos de manera fácil, y venda más.

Usted edita fotos, nombres, precios y stock desde su celular, rápido y sin saber de tecnología. Su cliente sapea el catálogo y le hace el pedido directamente por WhatsApp. Usted ahorra tiempo y deja de responder la misma pregunta veinte veces.

## ¿Para quién es?

Para pequeños emprendedores de todo el Perú que venden por WhatsApp, Instagram o TikTok: tiendas de ropa, cosméticos, bodegas y más.

## ¿Cómo funciona?

**Lo que ve su cliente:**

1. **Sapea el catálogo:** abre el enlace y ve fotos, precios y tallas. Puede buscar y filtrar.
2. **Elige:** entra al producto y escoge talla y color.
3. **Pide por WhatsApp:** el mensaje ya está escrito, solo lo envía.

**Lo que hace usted:**

- Actualiza sus productos desde el celular (Google Sheets o el panel de edición).
- Registra y sigue sus pedidos: Nuevo → Pagado → Empacado → Enviado → Entregado.
- Revisa el resumen de ventas del mes.

## Tecnologías

- Google Sheets (base de datos: pestañas Productos y Variantes)
- Google Apps Script (entrega los productos como JSON y el panel de edición)
- HTML, CSS y JavaScript (el catálogo)
- GitHub Pages (publicación gratuita)
